# Life Cashflow Simulator

住み替え後の家計を、現在の支払能力だけでなく、教育費・退職・物価・金利・修繕などを含む複数シナリオで検討するブラウザ完結型Webアプリです。

## 主な機能

- 楽観・標準・慎重の3シナリオ比較
- 住宅売却手取り、新居ローン、40年間の金融資産推移
- 安全圏・要注意・危険の判定
- 結果へ影響する入力値と是正案の表示
- マネーフォワード等のCSVをブラウザ内で解析
- 実績中央値と予測値の比較・反映
- 教育費、修繕、車などのライフイベント登録
- 入力項目ごとの参考値、計算方法、AI用計算プロンプト
- IndexedDBへの端末内保存
- JSONバックアップ・復元
- 判定スナップショット

## プライバシー

- CSVや入力値を外部サーバーへ送信しません。
- 元CSVは保存せず、月次・カテゴリ別の集計だけを端末内へ保存します。
- GitHubリポジトリにはプログラムと架空サンプルだけを置きます。
- 外部API、アクセス解析、CDNライブラリは使用していません。

## ローカル確認

静的ファイルのため、HTTPサーバーを起動して確認します。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

テストはNode.js 20以降で実行できます。

```bash
npm test
npm run check
```

## GitHub Pages

`main` ブランチへのpushで `.github/workflows/deploy-pages.yml` がテスト後にデプロイします。初回のみリポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定してください。

## CSV対応

次のような日本語・英語ヘッダーを自動判別します。

- 日付 / Date
- 金額（円） / Amount
- または 支出・収入 / Expense・Income
- 大項目 / カテゴリ / Category
- 振替 / Transfer

CSV形式や符号規則はサービス・出力時期によって異なる可能性があります。読み込み後の月次・カテゴリ集計を必ず確認してください。
