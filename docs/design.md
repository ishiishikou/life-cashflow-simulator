# Life Cashflow Simulator — Design

## 目的

住宅の住み替え可否を、現在時点の返済比率だけでなく、教育費、退職、物価、金利、修繕などを含む複数シナリオで判断する。予測値と家計実績の乖離を継続的に確認し、是正案の効果を比較できる状態を目指す。

## 設計原則

1. **分からなくても先へ進める**: 入力値は楽観・標準・慎重の幅を持ち、仮定値でも計算可能にする。
2. **根拠を保存する**: 実績、契約、本人計画、公的参考値、仮定値を区別する。
3. **端末内で完結する**: CSVはブラウザ内で解析し、元ファイルを保存・送信しない。
4. **是正可能性を示す**: 危険判定だけで終わらず、住宅価格、生活費、金利の変更効果を比較する。
5. **履歴を残す**: 判定スナップショットを保存し、実績追加後の変化を追跡する。

## MVP判定ロジック

- 住み替え直後資産 = 現在資産 + 売却価格 - 現ローン残高 - 売却費用 - 現金投入
- 新ローン元本 = 新居総額 - 現金投入
- 年末資産 = 前年資産 × (1 + 運用率) + 年間収入 - 年間支出
- 年間支出 = 基本生活費 + ローン返済 + 修繕保有費 + ライフイベント
- 危険: シミュレーション期間中に金融資産がマイナス
- 要注意: 最低資産が生活防衛資金未満、またはローン返済が月収の35%超
- 安全圏: 上記に該当しない

この判定は融資・税務・投資判断を代替しない概算である。
